# Contributing

Bug reports and pull requests are welcome on GitHub at
https://github.com/rjasper/ruby-matchers.

## Setup

```sh
git clone https://github.com/rjasper/ruby-matchers.git
cd ruby-matchers
bundle install
```

## Running tests

```sh
bundle exec rake        # runs tests and rubocop
bundle exec rake test   # tests only
```

## Feedback

The gem is in pre-release. If you have thoughts on the API, missing features,
or rough edges, opening an issue is the easiest way to share them.

## Pull requests

1. Fork the repo and create a branch from `master`.
2. Add tests for any new behavior.
3. Make sure `bundle exec rake` passes.
4. Open a pull request.

## Code of conduct

Contributors are expected to adhere to the
[code of conduct](https://github.com/rjasper/ruby-matchers/blob/master/CODE_OF_CONDUCT.md).
